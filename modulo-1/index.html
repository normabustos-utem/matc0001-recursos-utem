Suministro de Generación Eléctrica para Faena Vial

Como ingeniero(a) responsable de logística en una obra vial, debes contratar el grupo electrógeno de faena entre dos alternativas técnico-económicas para operar durante 30 horas con un presupuesto tope de $1.000.000 CLP:

α Proveedor Alfa

Costo Fijo Inicial (bA): $300.000 CLP
Costo Operativo por Hora (mA): $15.000 CLP / hora
Fórmula: C_A(x) = 15.000 · x + 300.000

β Proveedor Beta

Costo Fijo Inicial (bB): $100.000 CLP
Costo Operativo por Hora (mB): $25.000 CLP / hora
Fórmula: C_B(x) = 25.000 · x + 100.000

Paso 2: Modelación Algebraica y Funciones Lineales

Proveedor Alfa
C_A(x) = 15.000 · x + 300.000
m = 15.000 CLP/h (pendiente) | b = 300.000 CLP (intercepto)
Proveedor Beta
C_B(x) = 25.000 · x + 100.000
m = 25.000 CLP/h (pendiente) | b = 100.000 CLP (intercepto)

Deducción Algebraica con Símbolos Bicondicionales:

1. C_A(x) = C_B(x) ⟺ 15.000 · x + 300.000 = 25.000 · x + 100.000
2. 300.000 - 100.000 = 25.000 · x - 15.000 · x ⟺ 200.000 = 10.000 · x
3. x = 200.000 / 10.000 ⟺ x = 20 horas de faena
👉 Comprobación del Costo en Equilibrio:
C_A(20) = 15.000(20) + 300.000 = $600.000 CLP
C_B(20) = 25.000(20) + 100.000 = $600.000 CLP
