Suministro de Generación Eléctrica para Faena Vial

Como responsable de logística en una obra vial, debes contratar el grupo electrógeno de faena entre dos alternativas técnico-económicas:

α Proveedor Alfa

Costo Fijo Inicial (bA): $300.000 CLP
Costo Variable por Hora (mA): $15.000 CLP / hora

β Proveedor Beta

Costo Fijo Inicial (bB): $100.000 CLP
Costo Variable por Hora (mB): $25.000 CLP / hora

Paso 2: Modelación Algebraica y Funciones Lineales

Proveedor Alfa
C_A(x) = 15.000 · x + 300.000
Proveedor Beta
C_B(x) = 25.000 · x + 100.000

Deducción del Punto de Equilibrio:

1. 15.000·x + 300.000 = 25.000·x + 100.000
2. 200.000 = 10.000·x
👉 x = 20 horas (Costo = $600.000 CLP)
