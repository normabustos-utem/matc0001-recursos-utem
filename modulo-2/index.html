Diseño y Optimización de un Patio Rectangular de Almacenamiento

Como ingeniero(a) responsable de la planificación de una obra, debes diseñar un patio rectangular para almacenamiento de materiales utilizando exactamente 120 metros de cierre perimetral.

Paso 2: Deducción Formal del Modelo Cuadrático

1. Relación de Perímetro (Restricción)
2x + 2y = 120
x + y = 60
y = 60 − x
El largo y queda fijado en función de la elección del ancho x.
2. Función Objetivo: Superficie de Área
Área = x · y
A(x) = x · (60 − x)
A(x) = −x² + 60x
Forma estándar ax² + bx + c con a = −1, b = 60, c = 0.
Dominio Contextual de Validez Física: Dom(A) = (0, 60) metros

Paso 3: Optimización y Vértice de la Parábola

1. Concavidad: Como a = −1 < 0, la parábola abre hacia abajo (máximo absoluto en el vértice).
2. Coordenada del vértice: x_v = −b / (2a) = −60 / [2·(−1)] = −60 / −2 ⟺ x_v = 30 metros
3. Largo correspondiente: y = 60 − 30 ⟺ y = 30 metros
👉 Área Máxima Absoluta: A(30) = 30 × 30 = 900 m² (Patio Cuadrado)

Paso 5: Ecuaciones e Inecuaciones en Ingeniería

1. Condición Exacta: A = 800 m² (Ecuación Cuadrática)
−x² + 60x = 800 ⟺ x² − 60x + 800 = 0 ⟺ (x − 20)(x − 40) = 0
⟹ x₁ = 20 m (Patio 20×40) o x₂ = 40 m (Patio 40×20).
Ambas representan el mismo patio rotado 90° debido a la simetría respecto a x = 30 m.
2. Condición Mínima: A ≥ 800 m² (Inecuación Cuadrática)
−x² + 60x ≥ 800 ⟺ x² − 60x + 800 ≤ 0 ⟺ (x − 20)(x − 40) ≤ 0
⟹ Intervalo admisible por área: 20 ≤ x ≤ 40 metros.
3. Restricción Operacional de Tránsito: x ≤ 35 m
Intersección técnica: [20, 40] ∩ [0, 35] = [20, 35] metros.
